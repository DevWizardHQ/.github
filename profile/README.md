## About

DevWizard builds modern, scalable web applications and APIs — full-stack development with a focus on real-time systems, integrations, and clean, maintainable code.

## Tech Stack

- **Backend** — PHP, Laravel, REST/GraphQL APIs, MySQL, PostgreSQL, Redis
- **Frontend** — React, Vue.js, TypeScript, Inertia.js, TailwindCSS
- **Real-time** — WebSocket, live chat, video calling (WebRTC)
- **Integrations** — Stripe/PayPal payments, Twilio SMS, SendGrid/Mailgun email, Google Maps, social APIs
- **Infra** — Docker, Linux, Git, CI/CD, AWS/GCP/Azure

## Services

- Full-stack web & Laravel application development
- Real-time apps — chat, live collaboration, video calling
- Payment & API integrations
- Communication systems (SMS/email/notifications)
- Database design & optimization
- Technical consulting & architecture
